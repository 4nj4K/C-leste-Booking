# Céleste Booking

> A website for a skincare clinic, designed and built from scratch by a former skin therapist turned web developer.

**Live demo:** [Visit Céleste Booking](https://4nj4k.github.io/C-leste-Booking/)

---

## About the project

Before becoming a developer, I worked as a skin therapist at a clinic from 2021 to 2024. I spent a lot of time with clients and saw both what makes a clinic feel welcoming and what makes booking a treatment frustrating.

I have always loved design, so I wanted to create a clinic website where every choice was my own: the colors, the typography, the layout and the feeling of the page. Céleste Booking is the result. It combines my experience from the beauty industry with my skills in web development.

## Features

- Responsive layout built with HTML and CSS
- Interactive elements with vanilla JavaScript

## Roadmap

The site is meant to grow step by step into a complete clinic website. Planned next steps:

- [ ] **About us page** presenting the clinic and its therapists
- [ ] **Booking page** where clients can choose a treatment, date and time
- [ ] **Treatments page** with descriptions and prices
- [ ] Rebuild the frontend in React and TypeScript

## Tech stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Run it locally

1. Clone the repository:
   ```
   git clone https://github.com/4nj4K/C-leste-Booking.git
   ```
2. Open `index.html` in your browser.

No installation needed.
